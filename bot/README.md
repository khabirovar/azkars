# Регистрация Telegram-бота для Mini App

У бота в этом проекте нет своего сервера: он нужен только как точка входа, к которой
Telegram привязывает кнопку, открывающую веб-приложение. Весь процесс — переписка
с `@BotFather` в Telegram, ничего ставить локально не нужно.

## 1. Создать бота

1. Откройте чат с [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, следуйте подсказкам (имя, username, обязательно заканчивается на `bot`).
3. BotFather пришлёт токен вида `123456:ABC-DEF...`. Сохраните его в свой `.env`
   (см. `.env.example` в этой папке) и никогда не коммитьте реальный токен в git.

## 2. Привязать Mini App

Как только фронтенд задеплоен на GitHub Pages (см. `.github/workflows/deploy.yml`),
URL будет вида `https://<ваш-логин>.github.io/azkars/`.

- **Кнопка меню** (проще всего для одного приложения на бота):
  `/setmenubutton` → выбрать бота → отправить URL → задать подпись кнопки (например, «Открыть»).
- **Отдельная ссылка вида `t.me/<bot>/<app>`** (если нужен диплинк отдельно от меню):
  `/newapp` → выбрать бота → указать короткое имя приложения и тот же URL.

## 3. Не обязательно, но приятно

- `/setdescription`, `/setabouttext` — описание бота в профиле.
- `/setuserpic` — аватар.

## Тестирование до постоянного хостинга

Пока GitHub Pages ещё не настроен, можно временно пробросить локальный dev-сервер
(`npm run dev` в `/app`) через `ngrok http 5173` или `localtunnel` и указать
полученный HTTPS-адрес в `/setmenubutton`. Так получится проверить вибрацию,
`CloudStorage` и кнопку «назад» в реальном клиенте Telegram ещё до релиза.
